## 如何开始

按 [公开 README 的安装步骤](https://github.com/Yorushikamimimi/docdoc#怎么安装) 配置 Skill 与 MCP。需要 git、uv、Python 3.10+；Word 原生路线需要本机 Microsoft Word。

安装后提供已有 DOCX，并明确目标，例如：“把第三章标题改为 16 pt，其他地方别动。”
